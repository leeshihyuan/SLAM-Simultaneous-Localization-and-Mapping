## 序言

這本書的起點，是一個看似簡單的問題：一台機器人被放進一個陌生的房間，它如何知道自己在哪裡？

對人類而言，這幾乎不需要思考。我們一眼掃過房間，就能建立空間感、認出門的位置、知道自己站在哪個角落。但對機器人來說，這是一個需要感測器、數學、演算法與工程整合才能回答的難題——而且是過去四十年間，全球最頂尖的機器人研究者持續投入的核心課題。這個問題有一個名字：同步定位與建圖，SLAM。

### 本書的緣起

筆者在大學智慧機器人學程講授機器人導航相關課程多年，一直面臨同一個困難：中文的 SLAM 教材，要不是翻譯自英文而術語與台灣學界慣用法不一致，就是偏重數學推導而缺乏系統層面的視野；適合高中 AI 機器人社團課程的入門教材，更是幾乎空白。本書因此而生，目標是寫一本以繁體中文為母語、從觀念到實作、同時服務大學部與高中兩種讀者的完整教材。

### 本書的架構

全書分為九篇、三十一章，依循一條清楚的學習路徑：

第一篇建立觀念，說明 SLAM 要解決什麼問題、國際頂尖大學如何教這門學問。第二篇介紹機器人的六大感官——從里程計、IMU、光達到相機，逐一分析它們能做什麼、又會在什麼情況下失效。第三篇補足數學工具：座標轉換、機率估測與圖優化。

第四篇到第六篇是三套完整的 SLAM 系統：2D 光達 SLAM（含掃地機器人）、3D 光達 SLAM（含自主巡檢）、以及視覺 SLAM（從特徵到 ORB-SLAM3）。第七篇走向極限平台——毫瓦級的微型機器人、無人機與群體協作。

第八篇回到實作：ROS 環境建置、光達建圖導航、視覺 SLAM，以及完整的專題與評量標準。第九篇則展望未來，討論 AI 與視覺語言模型如何讓機器人從「知道形狀」進化到「理解意義」。

### 如何使用這本書

本書刻意設計成可依讀者層次選讀。高中課程可著重第一、二、四篇與各章的實作活動，多數實驗都能以模擬完成，不需昂貴硬體。大學部建議完整修習第一至六篇，並以第八篇的實作章節搭配課程進行。專題生與研究生則可直接進入第五、六、七、九篇，並以第三十章的專題設計作為研究起點。

每一章都採相同結構：學習目標、核心概念、完整課文、公式或流程、案例、實作活動、延伸閱讀與小結。其中「案例」與「常見失敗」的討論，是本書刻意強調的部分——筆者相信，理解一項技術在什麼情況下會失敗，比記住它在理想條件下的表現更有價值。

### 貫穿全書的一句話

如果要用一句話概括這三十一章，那就是：理解限制，才能突破限制。

書中反覆討論每一種感測器的弱點、每一個演算法的失效模式、每一個平台的資源約束。這不是悲觀，而是因為工程的本質就是在限制中求解。而人工智慧的加入並未改變這個本質——視覺語言模型讓機器人聽得懂、想得通，但走得穩、不撞人，仍然要靠紮實的幾何與控制。

### 致謝

感謝助教李天宇、李宇晴協助教材整理與實驗驗證；感謝歷屆修課同學以他們的提問、錯誤與突破，讓這本書的每一個案例都有真實的教學現場作為依據。也感謝全球 SLAM 社群長年開源分享的傳統——本書所介紹的系統，從 Gmapping、Cartographer 到 ORB-SLAM3，全部公開可取得。正是這個傳統，讓今日台灣的任何一位學生，都能站在世界頂尖研究的肩膀上。

最後，願讀者帶著這本書打下的基礎，去建造屬於自己的機器人——無論它是巡檢校園的機器狗、掃描古蹟的無人機，還是一台只會沿線走的小車。每一台能自己找到路的機器人，背後都是同一套人類花了四十年才建立起來的智慧。
